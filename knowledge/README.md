# Knowledge — личная база знаний

Всё, что ты хочешь помнить и к чему возвращаться. Заметки, инсайты, выжимки статей, ответы агента на вопросы, которые стоит сохранить.

## Как организовать

Начни просто. Кладёшь файлы сюда с понятными именами. По мере накопления — разбивай на подпапки по темам:

```
knowledge/
├── README.md (этот файл)
├── marketing/
├── sales/
├── finance/
├── team/
└── tools/
```

Агент сам предложит разбивку, когда накопится критическая масса.

## Правила

- **Один файл — одна тема.** Не склеивай всё в один большой документ.
- **Имя файла говорящее.** Не `note_01.md`, а `лестница_ценности_для_услуг.md`.
- **Frontmatter в начале**, чтобы находить через агент:

```yaml
---
title: "Название"
tags: [sales, skills]
source: "где узнал"
created: 2026-04-21
---
```

## Как использовать

Спрашиваешь агента: «а у меня что-то было про воронку продаж?» — он ищет в этой папке, в `context.md` и в `history.md`. Чем аккуратнее пишешь — тем точнее он находит.
