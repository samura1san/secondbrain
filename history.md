# History — лог событий и решений

> Сюда идут все значимые события по датам. Агент пишет сюда сам, когда ты обсуждаешь важные вещи. Ты тоже можешь — одной строкой.

## Формат

```
## YYYY-MM-DD

- [тип] что произошло
```

Типы:
- `meeting` — встреча
- `decision` — принял решение
- `deal` — сделка, оплата, контракт
- `launch` — запустили что-то
- `fix` — починили / решили проблему
- `note` — общая заметка

---

## 2026-04-XX

- [note] Начал курс AI LAB у Артёма Панферова. Создал свой Second Brain.
- [meeting] Первая встреча курса. Пара — `{{партнёр по интервью}}`. Обсудили: `{{ключевые темы}}`.

## 2026-04-XX

- 

---

## Как пользоваться

Пиши коротко. Одно событие = одна строка. Не нужно подробностей — для деталей есть отдельные файлы в `projects/` или `knowledge/`.

Когда через полгода захочется вспомнить «когда мы это решили» — история спасёт. Это твоя память по датам.
