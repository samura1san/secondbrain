# Templates — мои рабочие шаблоны

Сюда кладём шаблоны документов, которые ты используешь регулярно:

- письма клиентам
- коммерческие предложения
- брифы
- отчёты для команды
- регламенты

## Как добавить

Скажи агенту: «сохрани это как шаблон `<имя>`». Он создаст файл `templates/<имя>.md` с плейсхолдерами `{{}}`, которые нужно заполнять при использовании.

## Как использовать

«Сгенерируй КП для клиента X по шаблону `proposal.md`» → агент берёт шаблон, подставляет данные из `people/X.md` и `context.md`, выдаёт готовый документ.

## Примеры файлов

- `proposal.md` — коммерческое предложение
- `client_email.md` — первый контакт с клиентом
- `weekly_report.md` — отчёт команды за неделю
- `brief.md` — бриф на задачу
- `interview.md` — вопросник для собеседования

Начинай с 1–2 самых частых. По мере работы — добавятся ещё.
